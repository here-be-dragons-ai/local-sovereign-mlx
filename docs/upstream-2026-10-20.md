`v0.7.9` is `b8bf04c` + two PRs:

- **`#2545`**: CLI and Python `generate()` / `stream_generate()` take
  `temperature`, `top_p`, `top_k` from the checkpoint's `generation_config.json`
  when the caller passes none; before, they decoded greedily. The server
  already resolved them this way. Our tools are unaffected:
  `chat-kolibri.sh` passes all three, `measure-generation.py` has its own
  loop, the measurement scripts go through the server with explicit values.
  New scripts that want greedy must pass `temperature=0`.
- **`#2548`**: chunked prefill and continuation after a `RotatingKVCache`
  wraps; a shared `cache_position_offset()` in `models/base.py`, used by
  `qwen3_5` for the prompt-metadata offset. For `BatchKVCache` it returns
  `_idx`, the value used before; `BatchKVCache` itself is unchanged, so the
  invariant patch `0036` relies on (`offset == _idx - left_padding`) holds.
